KV cache rules of thumb

  • Old Llama-style 7B MHA in FP16 → ~0.5 MiB per token
  • 4K context → ~2 GiB KV
  • 32K context → ~16 GiB KV
  • FP8/INT8 KV cache = practical 2026 floor
  • Sub-8-bit KV cache = research territory, benchmark hard
