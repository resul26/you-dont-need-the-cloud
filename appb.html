Appendix B

Decision Trees for the Impatient

"Should I buy a GPU or just use the cloud?"

  • Do you have real privacy/sovereignty requirements? Yes → buy hardware eventually. No → keep reading.
  • Is your workload bursty and hard to schedule, and top quality is non-negotiable? Yes → keep the API. No → keep reading.
  • Do you run long agent workflows, batch work, or anything with predictable high token volume? Yes → local is almost certainly cheaper over 12+ months. No → keep reading, you might be fine either way.
  • Do you already own decent hardware (a Mac Mini with 32GB+, a desktop with a 3090+)? Yes → set up the local stack first, evaluate, then decide. No → rent a small weekly demo from RunPod or similar before buying.

"Which hardware should I get?"

  • Budget < $500 → small laptop-class local models only. Wait.
  • $1,000–$2,000 → refurbished 3090 (24GB) desktop, or a decent M-series Mac mini. Start here.
  • $3,000–$6,000 → new 4090/5090 desktop, or Mac Studio M4 Max. This is the real enthusiast tier.
  • $10,000–$25,000 → dual 5090 / dual RTX PRO workstation, Mac Studio M3 Ultra (512 GB). Production-quality local.
  • $25,000+ → serious talk about a multi-GPU server or DGX Spark cluster. Read Chapter 12 again, then Chapter 15.

"Which engine do I install first?"

  • Are you on a Mac? → MLX if you want maximum "Apple-native," llama.cpp if you want max compatibility.
  • Are you on a single NVIDIA consumer GPU? → llama.cpp if you want easy / portable. ExLlamaV2 if you want max per-card performance on that card.
  • Do you have 2–4 NVIDIA GPUs? → ExLlamaV3, or vLLM. Do not use llama.cpp here.
  • Are you serving more than 5 concurrent people? → vLLM. Period. Really.
  • Are you serving thousands of concurrent people or need structured output at scale? → Benchmark vLLM, SGLang, and TensorRT-LLM against each other.

"Which quantization should I use?"

  • Have memory to spare and need max quality? → FP16.
  • Want great quality with savings? → Q6_K or FP8.
  • Want the modern default? → Q4_K_M (GGUF) or EXL3 4bpw (ExLlama). This is the "just do this" answer.
  • Really need to squeeze? → Q3 with caution, test your tasks carefully.
