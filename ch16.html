Chapter 16

The 2026 Model Scene — an Ecosystem, Not a Horse Race

I'm going to save you from the most annoying conversation in tech right now: "which model is the best one?"

There is no bird. There is a barn. You are choosing an ecosystem: weights, license, tokenizer, chat template, quantization support, runtime support, deployment story, community tooling, failure modes.

As of mid-2026, the families worth tracking, per Ahmad's LLMs 101 and the broader 5ac analysis:

  • Qwen 3.5 / 3.6 — the most end-to-end family. Small laptop models all the way up to dense 27B workstation models, MoE setups for multi-GPU, FP8 variants, long context (up to 262K on the 27B), multilingual, coding, agentic. The default answer for an ecosystem that scales with you. Qwen 27B dense is the sweet spot for a 2×3090 setup when configured correctly.
  • Gemma 4 — Google's open family, Apache 2.0, multimodal, long-context on bigger sizes, efficient edge versions. Great when commercial use and device-side deployment matter.
  • Kimi K3 (Moonshot AI) — 2.8T params, MoE 16/896 experts, 1M context, the biggest open-weight model out of China as of July 27, 2026. Top of the agent leaderboard at release, second in WebDev. Custom license (not MIT) — read before you deploy.
  • GLM 5.2 (Z.ai) — within one percentage point of high-end commercial models on agentic benchmarks at roughly 1/5 the cost. Strong for coding agents, long-horizon tasks, MoE hosting.
  • DeepSeek V4 — 284B Flash / 1.6T Pro, 1M context, hybrid attention. Flash is the cheap frontier-tier API at $0.14 / $0.28 per 1M tokens; Pro at $0.44 / $0.87. Big MoE, MLA, sparse attention, FP8 serving paths, high-throughput self-hosting.
  • MiniMax — efficient MoE and agentic workloads.
  • Mistral — still important across generalist, coding, reasoning, multimodal, and specialist niches.
  • Nemotron 3 — NVIDIA's open family for agent systems on NVIDIA hardware, Nano/Super/Ultra, hybrid Mamba-Transformer MoE, deep ties to TensorRT-LLM, NIM, Dynamo, Blackwell NVFP4 paths. Treat it as "where NVIDIA serving is going," not a casual chat family.

Open-weight ≠ open-source. Read the license. Some are permissive, some are "weights are available," some are "research use only," some have use restrictions. Don't find out your commercial agent runs on a model with a noncommercial clause during due diligence. Read the card. Every time.
